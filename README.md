## ⚙️ Использование

### 1. Отключите антивирус

> [!WARNING]
> Некоторые антивирусы могут блокировать файлы лаунчера или помещать их в карантин.

### 2. Распакуйте архив

Извлеките содержимое архива в любую удобную папку.

```text
NewLauncher/
├── NewLauncher.exe
├── data/
└── config/
```

### 3. Запустите лаунчер

Откройте папку и запустите:

```text
NewLauncher.exe
```

> [!IMPORTANT]
> Не запускайте программу напрямую из архива. Сначала полностью распакуйте все файлы.

### ✅ Готово

После запуска откроется окно **NewLauncher** и программа будет готова к использованию.
